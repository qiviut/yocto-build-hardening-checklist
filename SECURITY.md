# Security policy

This repository contains a defensive checklist and review notes. It is not a runtime service and does not receive production credentials or build artifacts.

## Reporting a security issue in this checklist

For documentation errors or a proposed hardening improvement, open a GitHub issue with:

- the affected file and section;
- the exact claim or control;
- a reproducible source reference or test; and
- the proposed correction.

Do not include secrets, private source, patient data, unpublished vulnerabilities, or exploit payloads in a public issue. For a sensitive report, contact the repository owner privately through an established GitHub account channel and provide only the minimum necessary detail.

## Scope

The checklist is intended to help product teams secure Yocto/OpenEmbedded build environments. It does not replace upstream Yocto vulnerability reporting, a product manufacturer's incident process, or a regulatory quality system.
